# 24 考研全年规划

## 整体安排

{% note info no-icon %}

4 - 6 月 —— 基础阶段

7 - 9 月 —— 强化阶段

10 - 11 月 —— 冲刺阶段

12 月 —— 查漏补缺阶段

{% endnote %}

## 具体科目安排

### 考研英语

{% note info no-icon %}

**基础阶段：**

单词 + 语法长难句 + 阅读课 + 2010年前真题训练

**强化阶段：**

单词 + 长难句 + 2018年前阅读课 + 写作训练

**冲刺阶段：**

单词 + 长难句 + 作文模板 + 小三门 + 真题模考

**查漏补缺阶段：**

单词 + 写作训练 + 真题多刷

{% endnote %}

#### 单词、长难句安排

{% note success no-icon %}

**单词：**真题高频词 -> 真题低频词 -> 未考大纲词 -> 超纲词

**长难句：**每日一句 - 15分钟

{% endnote %}

### 考研数学

{% note info no-icon %}

**基础阶段：**

看基础网课 + 刷题

**强化阶段：**

看强化网课 + 大量刷题

**冲刺阶段：**

做历年真题

**查漏补缺阶段：**

多刷模拟卷，回顾错题集

{% endnote %}

#### 课程选择安排

{% note success no-icon %}

**整体安排：**小崔老师

**基础阶段：**

跟随小崔老师完成基础阶段视频课的学习（尽量跟直播课）

完成每一次作业以及测试（尽量在300名以内完成）

整理错题集

**强化阶段：**

跟随小崔老师完成强化阶段视频课的学习（尽量跟直播课）

掌握特色题目的特殊方法、一题多解

**冲刺阶段：**

刷历年真题

2010年之后真题必须完成 

2005 - 2009年真题尽量完成

**查漏补缺阶段：**

如果真题没有完成，优先做真题

在真题完成的情况下，做模拟题

回顾错题集

{% endnote %}

### 考研专业课

{% note info no-icon %}

**基础阶段：**

完成所有科目一刷 + 课后选择题

**强化阶段：**

二刷所有科目 + 错题 + 课后大题

**冲刺阶段：**

三刷错题 + 真题 + 模拟题

**查漏补缺阶段：**

再刷错题 + 保持手感

{% endnote %}

#### 课程选择安排

{% note success no-icon %}

**整体安排：**王道

**基础阶段：**

学习王道基础课程

一刷王道四门单科书

只做选择题

一两天搞不懂的直接跳过

**强化阶段：**

学习王道强化课程

二刷王道四门单科书

二刷错题以及王道课后大题

学习一刷时没有搞懂的知识点

**冲刺阶段：**

三刷错题（主要是大题）

继续学习前两阶段未搞懂的知识点

做真题、王道模拟题

**查漏补缺阶段：**

四刷错题（选择、大题、真题）

实在搞不懂的就放弃。

{% endnote %}
