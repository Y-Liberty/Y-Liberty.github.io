# 字符串

>
> 计算机读取二进制
>
> 人类读取字符串

# 字符和整数的转化——ASCII码

> ASCII 码表链接：https://baike.baidu.com/item/ASCII/309296?fr=ge_ala

> 每个常用字符都对应一个-128~127的数字，二者之间可以相互转化：

``` cpp
#include <iostream>

using namespace std;

int main(){
    char c = 'a';
    cout << (int)c << endl;
    int num = 78;
    cout << (char)num << endl;
    return 0;
}
```

> 常用ASCII值：’A’ - ‘Z’ 是 65 ~ 90，’a’ - ‘z’是 97 - 122，’0’ - ‘9’是 48 - 57。
>
> 字符可以参与运算，运算时会将其当做整数：

``` cpp
#include <iostream>

using namespace std;

int main(){
    int a = 'B' - 'A';
    int b = 'A' * 'B';
    char c = 'A' + 2;
    cout << a << endl;
    cout << b << endl;
    cout << c << endl;
    return 0;
}
```

> 打印ASCII码表

``` cpp
#include <iostream>

using namespace std;

int main(){
    for(int i = 1; i <= 128; i ++){
        cout << i << ": " << char(i) << endl;
    }
    return 0;
}
```

> **练习：**输入一行字符，统计出其中数字字符的个数，以及字母字符的个数。

``` cpp
#include <iostream>

using namespace std;

int main(){
    char c;
    int nums = 0, chars = 0;
    while(cin >> c){
        if(c >= '0' && c <= '9') nums ++;
        else if(c >= 'a' && c <= 'z') chars ++;
        else if(c >= 'A' && c <= 'Z') chars ++;
    } 
    cout << nums << " " << chars << endl; 
    return 0;
}
```

# 字符数组

> 字符串就是字符数组在末尾加上结束符 '\0'
>
> 结束符的意义是指明字符串在哪里结束，C++规定字符串的结束标志就是 '\0'
>
> 可以使用字符串来初始化字符数组，但此时要注意，每个字符串结尾会暗含一个’\0’字符，因此字符数组的长度至少要比字符串的长度多1！

``` cpp
#include <iostream>

using namespace std;

int main(){
    char a1[] = {'C', '+', '+'};		// 末尾没有'\0'，a1 为字符数组
    char a2[] = {'C', '+', '+','\0'};	// 末尾有'\0'，a2 为字符串
    char a3[] = "C++";					// 末尾自动添加表示字符串的结束符
    char a4[6] = "ABCDEF";				// 没有空间可以存放空字符，错误
    
   cout << sizeof a1 << endl; 
    
    return 0;
}
```

## I/O

### 输入

> 可以直接使用 cin / cout 进行输入输出
>
> 但是 cin 在输入的过程中不会识别空格，即当输入的字符数组包含空格时，当输入到空格就停止输入
>
> cout 在输出的过程中可以识别空格，即当输出遇到空格时不会停止。

``` cpp
#include <iostream>

using namespace std;

int main(){
    char str[100];
    // 输入测试1 ： “ABCDEF”
    // 输入测试2 ： “ABC DEF“
    cin >> str;
    cout << str << endl;  
    return 0;
}
```

> 想要输入包含空格的字符串时，需要用到 fgets() 函数.
>
> fgets() 函数当遇到回车才表示输入结束
>
> fgets() 函数默认三个参数，第一个参数填写 字符串名，第二个参数填写 字符串长度【表示最多读入到哪个字符】，第三个参数默认填写 stdin

``` cpp
#include <iostream>

using namespace std;
```

> 使用 scanf 也可以输入字符串
>
> 但是输入时要注意字符串不可以使用 & 
>
> 因为数组名自动指向首元素地址，无需再次引用
>
> 同样，scanf 和 cin 相同，不识别空格

``` cpp
#include <iostream>

using namespace std;

int main(){
    char str[100];
    scanf("%s", str)
    cout << str << endl;  
    return 0;
}
```



> 默认的输入的数组下标是从 0 开始的，
>
> 想要将下标从非零开始，可以在输入时，输入 数组名+数量 进行输入

``` cpp
#include <iostream>

using namespace std;

int main(){
    char str[100];
    cin >> str + 1;
    // scanf("%s", str + 1);     // 同样效果
    cout << str + 1 << endl;  
    return 0;
}
```

## 常用函数

> 下面几个函数需要引入头文件:

``` cpp
#include <cstring>
```



> (1) strlen(str)，求字符串的长度
>
> (2) strcmp(a, b)，比较两个字符串的大小，
>
> a < b 返回-1，
>
> a == b 返回0，
>
> a > b返回1。
>
> 这里的比较方式是字典序！【acsii 码小的就小】 
>
> (3) strcpy(a, b)，将字符串b复制给从a开始的字符数组。

``` cpp
#include <iostream>
#include <cstring>

using namespace std;

int main(){
    char a[100] = "Hello World!";
    cout << strlen(a) << endl;
    
    char b[100] = "abc";
    char c[100] = "aaa";
    cout << strcmp(b, c) << endl;
    
    char d[100];
    strcpy(d, a);
    cout << d << endl;
    return 0;
}
```

### 遍历字符串

> 字符串本质是字符数组，所以和数组的遍历方式相似
>
> 在读取长度时，用 strlen 函数读取

``` cpp
#include <iostream>
#include <cstring>

using namespace std;

int main(){
    char a[100] = "Hello World!";
    for(int i = 0; i < strlen(a); i ++ ){
        cout << a[i] << endl;
    }
    return 0;
}    
```

# 标准库类型 string

> 可变长的字符序列，比字符数组更加好用。需要引入头文件：

``` cpp
#include <string>
```

## 定义和初始化

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
    string s1;				// 默认的空字符串
    string s2 = s1;			// 定义一个 s2 与 s1 相同
    string s3 = "abcdefg";	// 直接初始化字符串
    string s4(10, 'c');		// 定义一个字符串，初始化为 10 个 c [cccccccccc]
    return 0;
}
```

## 输入输出

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
   	string s1, s2;
    cin >> s1 >> s2;
    cout << s1 << " " << s2 << endl;
    return 0;
}
```

> 直接使用 cin 输入同样不识别空格
>
> 想要识别空格需要用函数 getline 实现

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
	string s;
    getline(cin, s);
    cout << s << endl;
    return 0;
}
```

## 常用操作

### 清空字符串

> str.empty() 可以判断当前字符串是否为空

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
	string s1 = "abc";
    cout << "before empty" << s1 << endl;
    
    s1.empty();
    cout << "after empty" << s1 << endl;
    return 0;
}
```

### 计算长度

> str.size() 可以计算字符串的长度

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
	string s1 = "abc";
    cout << s1.size() << endl;
    return 0;
}
```

### 查找子串

> str.find("Hello") 可以在当前字符串中找出子串的位置

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
	string s1 = "Hello World!";
    cout << s1.find("Wor") << endl;
    return 0;
}
```

### 获取子串

> str.substr(num1, num2) 可以获取一段子字符串
>
> num1 表示要开始获取的位置， num2 表示要获取的长度

``` cpp
#include <iostream>
#include <string>

using namespace std;

int main(){
	string s1 = "ABCDEFGHIJKLMNOPQLSTUVWXYZ";
    cout << s1.substr(7, 5) << endl;
    return 0;
}
```
